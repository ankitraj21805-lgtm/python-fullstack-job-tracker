# Python Full Stack Job Tracker

A full-stack job application tracking system built with a Python FastAPI backend, SQLite database, and responsive frontend dashboard for managing job applications, statuses, companies, roles, notes, and follow-ups.

## Live Demo

[View Live App](https://python-fullstack-job-tracker.onrender.com)

## Overview

This project demonstrates end-to-end full-stack development with backend APIs, database CRUD, frontend integration, and deployment. It is designed as a practical career-management tool and a recruiter-friendly GitHub project.

## Features

- Add job applications
- View all applications in a dashboard
- Track application status
- Store company, role, notes, and follow-up data
- SQLite database persistence
- FastAPI REST endpoints
- Frontend-to-backend connection
- API documentation support
- Render deployment-ready structure
